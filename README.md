### No script [luanti.sh][luanti.sh], se atentar as linhas:
---
- 4: Verificar se o local bate com a pasta onde o Luanti (Minetest) guarda os mundos criados;
- 24: Verificar se quer realmente abrir na porta 30000;

### Dicas
---
- Para abrir publicamente é necessário solicitar ao seu povedor de internet para abrir a porta que deseja utilizar (e.g 30000) publicamente, assim outras pessoas com seu endereço IP podem usar seu servidor, acaso a porta utilizada for diferente de 30000 (padrão) lembrar de solicitar aos usuários modificarem a porta padrão dentro do jogo antes de se conectarem;
- Para anunciar seu servidor na listagem do luanti é necessário que seu 'minetest.conf' tenha 'server_announce = true';
- Verificar os itens server_announce, enable_server, port, name, remote_port, address de seu minetest.conf antes de subir seu servidor;
